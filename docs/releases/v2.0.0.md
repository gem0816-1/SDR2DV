# SDR2DV v2.0.0

下载 `SDR2DV-v2.0.0-win-x64.zip`，解压后双击 `deploy.bat`，再双击或拖视频到 `SDR2DV/TrueHDR-DV.bat`。

- 新增中文终端界面：方向键选择、各级选项灰色说明、Esc 返回、配置摘要、阶段进度与安全取消。
- 默认使用 DV8.4 / BT.2020 HLG / HEVC Main10 / 1000 nit 参考峰值，Auto 优先使用实测可用的 NVENC。
- 默认匹配源视频流平均码率；平台限码率为显式选项。输出报告显示源、目标、实际码率和偏差。
- 音频优先复制；受支持的整数 PCM 无损转 ALAC，验证位深、采样数、解码采样和音画偏移。
- 新增 Natural 实验曲线、同次推理的 HDR10/PQ 对照、最终像素亮度统计和社区镜头级 RPU 分析。
- 修复 Windows 大帧管道 `Errno 22`、进度文件共享冲突及父日志管道失效；失败时先保存小型诊断，再清理本次媒体缓存。

验证：71 项测试中 68 项通过、3 项条件测试跳过；4K/60fps 600 帧完整转换与音频采样校验通过；4,096 帧、约 156 GiB 管道数据 CRC32 一致。

Natural 仍需 HDR 设备观感验收，默认保留 Neutral。码率目标不保证预算用满，同码率不等于无损；本次 10 秒样本实际码率低于目标，已如实报告。
1000 nit 是参考目标，最终像素可能因重建和有损编码超调。社区 RPU 分析不是 Dolby 官方认证调色。
202.15 秒原片未在修复后整片重跑；B站 DV / Hi-Res 投稿、服务器转码和最终播放仍待实测。

发布包不含用户媒体、配置、虚拟环境或 NVIDIA SDK；首次部署需要网络与兼容硬件。封装器许可证及对应上游源 ZIP 随 Release 提供。
详细运行方式见 [使用说明](../usage.md)，测试边界见 [验证说明](../validation.md)。
