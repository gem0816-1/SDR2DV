# SDR2DV v2.1.0

新增独立 `realDolby` 亮度曲线及浮点 HLG 超白管道，按配对苹果参考视频校准明暗关系。解压 `SDR2DV-v2.1.0-win-x64.zip` 后双击 `deploy.bat`，再运行 `SDR2DV/TrueHDR-DV.bat`，在「HDR亮度映射」选择 `realDolby`。

- `realDolby` 保持零黑位、调整中低调并保留参考高光，不按1000 nit截顶；1000 nit只是SDK校准基准与HLG测量参考。默认仍为Neutral。
- 扩展信号通过float32传给编码器；HDR10/PQ对照也保留超过1000 nit的像素。已有Neutral缓存可通过浮点适配器复用，不重复AI推理。
- TUI、PowerShell CLI、缓存核验、输出命名和报告均支持新曲线，新增配对HLG亮度比较工具；详见[校准说明](../realDolby.md)。
- 源视频流码率匹配、NVENC Main10、音频复制优先以及经采样校验的PCM→ALAC无损封装继续沿用。

本地验证：81项CPU/静态测试中76通过、5项条件跳过；另外实际运行3项CUDA数值测试和1项NVENC无损回读测试，均通过。4K/60fps、8秒480帧样片经完整管线输出MP4/MKV及同次推理的HDR10/PQ，RPU/帧数、48kHz/24bit音频采样与音画同步校验通过；Neutral缓存复用路径另经30帧实际转换验证。

新成片8个配对抽样画面的PQ亮度误差减少58.8%，这衡量与该参考的亮度接近程度，不是画质分数。用户对该8秒DV样片反馈“整体接近参考”；此次反馈未进一步确认设备/播放器版本或DV标识。

曲线不能恢复SDR已剪切的信息，也不复制苹果参考的创作Trim。未执行223.05秒整片新版转换、B站投稿或服务器音频回读；不宣称其他素材、DV播放链或B站Hi-Res已全部验收。

发布包只含代码、文档及附许可证的社区mp4muxer，不含视频、验证日志、虚拟环境、本机配置或NVIDIA SDK。下载后可对照 `SHA256SUMS.txt` 校验。
